# FamBean i18n Glossary 术语表

For translators and contributors working on `frontend/src/i18n/en.ts`.
`zh-CN.ts` is the source language; `en.ts` must implement `Record<MessageKey, string>` with exactly the same keys.

## 1. Core accounting terms 账务术语

| 中文（源语言） | English（定稿） | Usage note |
|---|---|---|
| 账本 | Ledger | A book shared by a family; never "book". |
| 账户 | Account | Beancount account, e.g. `Assets:Cash:CNY`. |
| 交易 | Transaction | One dated entry with postings. Never "record" as a noun. |
| 分录 | Posting | One debit/credit line inside a transaction. |
| 冲正 | Reversal | Immutable edits: reversal + new transaction. Never "reverse entry". |
| 期初余额 | Opening balance | Initial balance of an account. |
| 余额校准 | Balance calibration | Not "reconciliation"; see Reconciliation below. |
| 导入批次 | Import batch | Undo unit for a Beancount import. |
| 回收站 | Trash | Soft-deleted transactions. |
| 永久删除 | Purge | Physical delete; only the ledger owner can purge. |
| 标签 | Tags | Stored as `tags: "..."` metadata, not `#tag`. |
| 标记 | Flag | Beancount flag `*` (complete) / `!` (incomplete). |
| 期初权益 | Opening equity | Equity account absorbing opening balances. |
| 对账 | Reconciliation | Only for external bank/statement matching; keep "reconciliation". |

## 2. Commodity vs. Currency 币种用词边界

| 场景 | 用词 | 说明 |
|---|---|---|
| Technical docs, API fields, Beancount data | Commodity | e.g. `commodity` field, `postings.commodity`. |
| User-facing UI copy | Currency | e.g. "New currency", "Currency code", "Currencies". |

Do not mix them inside one screen: field labels and messages shown to users say **Currency**.

## 3. Member roles 成员角色

| 中文（源语言） | English（定稿） | Note |
|---|---|---|
| 所有者 | Owner | Ledger-level owner; not the system administrator. |
| 编辑者 / 编辑 | Editor | Can create and edit transactions. |
| 只读成员 | Viewer | Role label is "Viewer"; adjective form "view-only" is fine in sentences. |
| 系统管理员 | Administrator | Global admin (`users.is_admin`), not a ledger role. |

## 5. Translation rules 翻译规则

| Rule | Detail |
|---|---|
| Source of truth | `zh-CN.ts`; never edit Chinese values. |
| Key parity | `en.ts` is `Record<MessageKey, string>`; missing/extra keys fail typecheck. |
| Placeholders | Keep `{n}` `{name}` `{date}` `{amount}` `{count}` etc. verbatim; never rename or drop them. |
| Fallback | Missing English falls back to Chinese, then to the key itself. |
| Style | Sentence case; buttons use imperative or noun phrases (Save / Cancel / Retry / Trash). |
| Length | Short slots (nav, tabs, buttons) stay ≤ 14 characters. |
| Formatting | Never change number, date, currency symbols (`¥`, `—`, `·`) or layout order. |
| Characters | No special typographic control characters (iOS 14.8 / Safari 14.1 baseline). |

## 6. Do NOT translate 禁止直译

| Item | Example | Why |
|---|---|---|
| Beancount syntax tokens | `tags: "..."`, flag `*` / `!`, `open`, `balance`, `pad` | Must match exported `.beancount` and `bean-check`. |
| Account names | `Assets:Cash:CNY`, `Expenses:Food` | Data, not UI copy. |
| Currency codes / symbols | `CNY`, `USD` | Data. |
| CSV headers produced by the export code | `date`, `description`, `postings` | Generated by server code, not the dictionary. |
| System-generated ledger data | default descriptions 「转账」/「记一笔」, `<待选账户>` | Written into the ledger and exported; must not drift with UI language. |
| Backend contract literals | `RESTORE`, purge confirm word `删除` | Validated literally by the server; localizing breaks the request. |
| User-entered content | tags, notes, display names | Data owned by the user. |
