### 0.1 Windows 启动（PowerShell）

```powershell

# 启动后端（托管 frontend/dist）
```

### 0.2 查手机可访问的地址

```powershell
Get-NetIPAddress -AddressFamily IPv4 |
  Where-Object { $_.IPAddress -notmatch '^(127\.|169\.254\.)' } |
  Select-Object IPAddress, InterfaceAlias
```

手机访问 `http://<电脑局域网IP>:8080`；首次启动 Windows 防火墙弹窗需允许专用网络。

### I1 账单页 `/`（原首页已下线）

- [ ] I1.1 冷启动登录后落在 `#/`，页面标题为「账单」，地址栏不是 `#/transactions` 也不是旧首页
  - 失败时说明什么：若落在 `#/transactions`，说明旧流水路由仍被当成默认页（它现在只该是一个带 query 透传的重定向）；若白屏但侧栏在，说明 `BillsView` 渲染抛错，先看控制台第一条红字而不是网络面板
- [ ] I1.2 加载态：限速/弱网下首次进入，出现加载骨架或加载态卡片，**不出现**「本月还没有记账」
  - 失败时说明什么：若加载中就显示空态文案，说明 `pageState` 把 `!loaded` 判成了 empty —— 用户会把「还没拉到」读成「这个月没花钱」，这是最容易被当成数据丢失的一类误判
- [ ] I1.3 空态：选一个没有任何交易的月份，出现空态卡 +「记一笔」入口，且**仍能切月 / 切账本**
  - 失败时说明什么：若空态下切月箭头消失，页面成死路（用户只能杀掉应用重进）；若空态文案说的是「加载失败」，说明空态与错误态的文案串了
- [ ] I1.4 错误态：断网后冷启动，出现错误卡 +「重试」按钮，且工具卡（账本 / 月份）仍可用
  - 失败时说明什么：若整页只剩一行英文或 `undefined`，说明错误态直接把异常对象渲染出来了；若切月按钮也灰掉，说明错误态吞掉了工具卡
- [ ] I1.5 就绪态：日历按当月自然日排布（周一起始），格内是当日金额简写，支出红、纯收入日绿、同日有收入时右上角有圆点
  - 失败时说明什么：若某天明明既有收入又有支出却只显示支出且没有圆点，说明「收入圆点」没画（日历只算了一个方向）；若 2 月出现 30/31 格，说明格子数写死成 31
- [ ] I1.6 四指标（收入 / 支出 / 结余 / 交易数量）与日历、下方明细三处数字一致，且结余 = 收入 − 支出
  - 失败时说明什么：若结余符号反了，说明减数被取反；若「交易数量」与明细行数不等，说明数量里漏算或多算了转账 / 期初（它们计入笔数但不计入收支）
- [ ] I1.7 趋势图：横轴为当月 1..N 日（N = 当月天数），两条线为每日收入 / 支出；切到 2 月后横轴变成 28/29
  - 失败时说明什么：若 2 月横轴仍是 31，说明横轴标签按固定 31 天生成；若切月后指标变了但曲线不动，说明图表没监听月份变化（重绘依赖漏了 month）
- [ ] I1.8 点某日：该日高亮、下方明细只剩当日、出现「查看整月 ✕」；再点同一天取消选中并恢复整月
  - 失败时说明什么：若点了没反应，先确认点击是否落在格子本体（iOS 14 上若父层有 `touch-action` / `pointer-events` 设置会吞掉点击），而不是直接怀疑数据；若选中后明细不变，说明选中日没有参与列表过滤
- [ ] I1.9 切月：`‹` / `›` / 点月份弹选择器三条路径都能切，切完后日历、指标、趋势、明细**四块同时**更新
  - 失败时说明什么：只更新了一部分，说明四块各取各的数据源（应统一来自同一个当月快照）；跨年切换（12 → 1 月）若年份不变，说明月份加减没处理进位
- [ ] I1.10 当月明细：按日分组，组头有当日支出 / 收入小计；转账 / 期初 / 冲正以中性 badge 展示，不进收支合计；点整行进详情，返回后仍停在该月与选中日
  - 失败时说明什么：若转账被算进「支出」，说明整笔判定退化成了「有金额就算收支」；若从详情返回后跳回本月 1 日或筛选被清空，说明页面状态只存在组件内存里、没写回 query

### J7 ECharts 触摸专项（iOS 14.1 Safari 硬门槛）

> 本项目图表是 **ECharts 5.6 + SVG renderer**（`frontend/src/core/charts/echarts.ts` 是唯一 init 出口，renderer 固定 `svg`）。
> 排查时**不要照抄常见 Canvas 教程**（canvas 坐标换算、`devicePixelRatio` 缩放、`getBoundingClientRect` 偏移那一套在这里都不是主因）：
> SVG renderer 下图形是一堆 DOM 节点，问题通常出在**事件能不能到达节点**（`pointer-events` / `touch-action` / 覆盖层挡住的 `z-index`）与**容器尺寸在旋转后是否为 0**。

- [ ] J7.1 折线图 tooltip：手指**按住**某点并拖动，tooltip 出现并跟随；抬起手指后消失
  - 失败时说明什么：按住没反应但外接鼠标悬停有反应，说明只在 `mousemove` 上挂了逻辑而触摸事件没被转发到 SVG 节点；tooltip 出现但位置偏移到屏幕外，说明 tooltip 容器被放在了有 `transform` 的祖先里（SVG 下位置是 DOM 定位，不是 canvas 像素）
- [ ] J7.2 柱状图单击下钻：点**柱体本身**（不是标签）能触发，且响应在 300ms 内、不出现双击缩放
  - 失败时说明什么：只有点柱顶文字才响应，说明命中区域没覆盖整列；点了先放大页面再触发，说明缺少 `touch-action: manipulation`（iOS 14 会等双击判定）；响应要等 300ms 以上，说明绑了 `click` 而没处理触摸抬起
- [ ] J7.3 横屏旋转（竖 ⇄ 横）后图表重绘：图形填满容器、不出现半宽 / 空白 / 变形；旋转后 tooltip 仍可触发
  - 失败时说明什么：旋转后图表只有原来一半宽度或整块空白，说明 resize 时容器宽度被读成了 0（旋转瞬间布局未完成），需要在 `orientationchange` 后再 resize；旋转后点击错位，说明 SVG 覆盖层尺寸没跟着变
- [ ] J7.4 切到后台（Home 键）再切回：图表仍在、不白屏、数据不丢
  - 失败时说明什么：回来后图表区空白，说明初始化实例被复用了但容器被重建（需要 `dispose` 后重建）；数据丢失说明切后台时组件被卸载又没重新拉数据
- [ ] J7.5 图表卡片出错时的降级：断网 / 数据异常时显示错误态，**不出现半张图或永久骨架**
  - 失败时说明什么：永久 spinner 说明失败分支没接到状态机；半张图说明数据缺字段时仍调了 `setOption`
