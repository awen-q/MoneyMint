## 0. 启动与准备

### 0.1 Windows 启动（PowerShell）

```powershell
# 首次或前端有改动时先构建
cd d:\Project\Self\FamBean\frontend; npm run build; Set-Location ..

# 启动后端（托管 frontend/dist）
$env:PATH="$env:PATH;D:\Environment\go\bin"
$env:LEDGER_WEB_ROOT="frontend/dist"
$env:LEDGER_DB="data/ledger.db"
$env:LISTEN=":8080"
go run ./cmd/server
```

已构建过、只想启动时，去掉第一行构建命令即可。

### 0.2 查手机可访问的地址

```powershell
Get-NetIPAddress -AddressFamily IPv4 |
  Where-Object { $_.IPAddress -notmatch '^(127\.|169\.254\.)' } |
  Select-Object IPAddress, InterfaceAlias
```

手机访问 `http://<电脑局域网IP>:8080`；首次启动 Windows 防火墙弹窗需允许专用网络。
